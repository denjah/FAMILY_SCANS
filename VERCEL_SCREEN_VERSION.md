# Лёгкая экранная версия для Vercel

Исходники из `Z:/SCAN` на Vercel переносить не нужно: это медленно, дорого и не даёт пользы при просмотре на телефоне. Публикуется отдельная семейная версия, где для каждого снимка остаются только две производные копии:

- `thumb` — WebP до 560 px для сетки;
- `screen` — WebP до 2048 px для просмотра на экране.

Оригиналы, PSD и TIFF остаются дома на диске Z. В публикацию также не включаются резервные варианты, если не нужна кнопка их просмотра. Если кнопка нужна, для каждой старой версии создаётся только такой же `screen`-файл, а не оригинал.

## Рекомендуемая схема

```text
Z:/SCAN originals ──> генератор WebP ──> Cloudflare R2 (screen + thumb)
                                      └──> Vercel (Next.js интерфейс)
```

Vercel хранит только интерфейс и JSON-индекс. Файлы WebP размещаются в R2 с CDN; для семейного доступа лучше выдавать короткие подписанные URL из Vercel API, а не делать бакет публичным. Это не расходует диск C и не требует постоянно включённого домашнего компьютера.

Комментарии нельзя оставлять в SQLite внутри Vercel: её файловая система не является постоянным хранилищем. Для экранной версии таблица комментариев переносится в managed Postgres (например, Neon). Тогда мамина запись сохраняется с именем и временем, а вы видите её после входа владельцем с любого устройства.

## Что делать перед публикацией

1. Прогнать индексатор и заранее создать превью на диске `Z:/SCAN/SYSTEM_WEB/generated`.
2. Проверить выбор основной версии в локальной галерее и при необходимости переименовать спорные варианты с понятным суффиксом (`_C`, `_4x`, `_UP06`).
3. Загрузить только WebP-превью и индекс в R2, затем подключить Vercel к отдельному Git-репозиторию интерфейса.
4. Указать в Vercel секреты с доступом к R2 и семейный пароль. Оригиналы и локальный SQLite туда не отправлять.

До подключения R2 текущая локальная версия продолжит работать: кэш превью и все производные файлы остаются в `Z:/SCAN/SYSTEM_WEB/generated`, а не на C. Для окончательной публикации потребуется выбрать/создать R2-аккаунт и дать доступ к Vercel-проекту.

## Вход и восстановление доступа

1. Архив открывается по персональной ссылке-приглашению и семейному паролю. При первом входе человек указывает имя — оно сохраняется у всех его комментариев.
2. Сессия хранится только в защищённой HTTP-only cookie и истекает через 7 дней. Подбор пароля ограничен по IP-адресу.
3. На странице входа есть «Забыли пароль?» с адресом архивариуса `denjah@gmail.com`. Человек отправляет запрос со знакомого вам адреса, не указывая старый пароль. Вы проверяете личность и создаёте новый семейный пароль; старый отзывается увеличением `ARCHIVE_SESSION_VERSION`.
4. Не отправляйте существующий пароль письмом. Автоматические письма с одноразовой ссылкой можно добавить после подключения почтового провайдера (например, Resend) и домена; для этого понадобятся его ключи и подтверждение домена.
